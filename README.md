# 윤가영 포트폴리오 사이트

윤가영 교수의 포트폴리오 내용을 바탕으로 제작한 Next.js 포트폴리오 사이트입니다. Vercel 배포를 전제로 구성했습니다.

## 주요 구성

- 큰 타이포그래피 중심의 히어로 섹션
- 연구·교육 역량을 보여주는 포트폴리오 카드 그리드
- 프로필, 경력, 학력, 연락처 섹션
- 모바일 화면까지 대응하는 반응형 레이아웃

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 실행되면 `http://localhost:3000`에서 확인할 수 있습니다.

## 배포

Vercel에서 이 저장소를 연결하면 Next.js 프로젝트로 자동 감지됩니다. 기본 설정으로 배포할 수 있습니다.
